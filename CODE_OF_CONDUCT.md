# Code of Conduct

## Pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Standards

- Be respectful and constructive.
- No harassment, doxxing, or personal attacks.
- Do not request or share attack capabilities against systems without authorization.
- Assume engagement data is confidential.

## Enforcement

Maintainers may reject contributions, ban users, or report illegal activity. Report conduct issues to the maintainers listed in the GitHub org.

This policy is adapted from the Contributor Covenant, version 2.1.

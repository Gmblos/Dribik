# Payload sources

The checked-in lists contain curated, deduplicated entries inspired by these
public research wordlists. They are included for authorized testing only.

- LFI: [PayloadsAllTheThings JHADDIX_LFI](https://github.com/swisskyrepo/PayloadsAllTheThings/blob/master/File%20Inclusion/Intruders/JHADDIX_LFI.txt)
- SQLi: [Auto_Wordlists sqli.txt](https://github.com/carlospolop/Auto_Wordlists/blob/main/wordlists/sqli.txt)
- Subdomains: [dnscan subdomains-1000](https://github.com/rbsec/dnscan/blob/master/subdomains-1000.txt)
- XSS: [payload-box/xss-payload-list](https://github.com/payload-box/xss-payload-list)

Destructive database/file-modifying probes are intentionally excluded. Review
scope and program rules before using any active scanner.
